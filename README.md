## Описание
Бэкенд веб-сайта для аренды одежды, разработанный на Django. Проект реализует полный цикл работы с объявлениями: от создания и кастомной модерации до поиска, редактирования и оставления отзывов.

## Реализованный функционал
-  Регистрация и аутентификация пользователей (с безопасной настройкой сессий).
-  Создание, редактирование и удаление объявлений (доступно только владельцу).
-  Поиск и фильтрация объявлений (по ключевым словам, локации, минимальной и максимальной цене).
-  Кастомная модерация объявлений перед публикацией (интерфейс доступен только пользователям с правами `is_staff`).
-  Система обратной связи (возможность оставлять отзывы к объявлениям).
-  Сокрытие контактной информации продавца для неавторизованных пользователей.
-  Unit-тесты ключевых функций приложения с логированием результатов.
-  Безопасное хранение секретных ключей и данных БД через переменные окружения (`.env`).

## Стек технологий
- Python 3.10+
- Django 5.x
- PostgreSQL
- Bootstrap 5 (frontend-стилизация)
- `unittest`, `logging`
